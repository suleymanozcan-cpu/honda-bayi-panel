# Honda Bayi Sosyal Medya Denetim Paneli

Tarayıcıda çalışan manuel veri girişli demo.

## GitHub yükleme
`index.html` dosyasını deponun ana dizinine yükleyin. Vercel üzerinden statik proje olarak yayınlayın. Framework preset: Other, build command boş, output directory boş veya `.`.

## Sınırlar
- Instagram/Meta API bağlantısı yoktur.
- Veriler yalnızca kullanılan tarayıcının localStorage alanında saklanır.
- Kullanıcı girişi ve merkezi veritabanı yoktur.
- Honda puan ağırlıkları belgeden alınmıştır; detaylı otomatik puanlama formülü tanımlı olmadığından puanlar manuel girilir.
- Demo, kurumsal onaylı resmi Honda uygulaması değildir.
